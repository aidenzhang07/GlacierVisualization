Source Code

Open on GitHub

The repository contains the Flask backend, frontend web interface, and geospatial data-processing tools used throughout the project. It includes scripts for processing GLIMS glacier outlines, filtering GlaThiDa datasets, generating reference glacier data, and serving interactive glacier visualizations.

Run locally with Python and Flask using the dependencies listed in the requirements file. Additional setup instructions and documentation are included in the GitHub README.
