Downloading satellite imagery…

How to read this map. Click any glacier polygon to see its record. Outline colors and thickness indicate data coverage.

Outline type 01

Multi-observation glacier

Purple outline. This glacier has two or more observations in GLIMS — enough to show change over time.

Outline type 02

Single observation glacier

Dark blue outline. Only one recorded outline in GLIMS — no time-series comparison available.

Outline type 03

Extinct glacier

Red outline. GLIMS records a gone_date — this glacier no longer exists.

Interacting with the map

Click any polygon to open its data popup. Use the layer switcher (top right) to change base maps. Click Transition to step through historical outlines.
